# Quick RRL Processing Guide

## 🚀 **Fast Workflow When You Find New Papers**

### Method 1: Abstract Analysis (5 minutes)
1. **Copy-paste abstract** into `Abstracts/[Author_Year].md`
2. **Tell me**: "Analyze new paper abstract" + paste text
3. **I provide**: Relevance score, Consol mapping, chapter placement
4. **You decide**: Keep for full analysis or skip

### Method 2: Key Section Analysis (15 minutes)  
1. **Extract key sections** (intro, results, conclusions)
2. **Paste into** `Key_Excerpts/[Author_Year].md`
3. **I analyze**: Methods, findings, direct thesis relevance
4. **I create**: Ready-to-use analysis file

### Method 3: Citation Mining (10 minutes)
1. **Share reference list** from promising papers  
2. **I identify**: High-potential papers to search for
3. **I prioritize**: Based on title/journal relevance
4. **You search**: Focused list instead of random hunting

## 💡 **PDF Text Extraction Tips**

### Free Tools to Convert PDFs:
- **Adobe Reader**: Copy text directly
- **Google Docs**: Upload PDF, auto-converts
- **Online converters**: PDF to text/markdown
- **Research databases**: Often provide text versions

### What to Extract:
- **Abstract** (always)
- **Introduction** (context setting)
- **Results/Findings** (main contributions) 
- **Conclusions** (implications)
- **References** (citation mining)
